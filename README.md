# Monitor Mount Notes

Original independent editorial about monitor arms for small desks. Buildless HTML, custom CSS, original SVG diagrams, and a browser-local preliminary fit checker.

Live site: https://dannischros-star.github.io/monitor-mount-notes-2026/

## Preview

Run Python's http.server bound to 127.0.0.1 on port 8765 in this directory. No build step or dependency installation is required.

## Editorial boundaries

Manufacturer documents are linked on the comparison and buying-guide pages. Specifications consulted October 27, 2026. No hands-on tests, platform approval, established audience, sponsorship, or commissions are claimed. No paid links currently. The checker is not a safety certification. It does not inspect desk material, clearance, screen depth, fasteners, or adapters.

## Privacy and feedback

No analytics, external fonts, storage or collection forms. Checker values stay in browser memory. Hosting requests are handled by GitHub Pages. Corrections: use public Issues without personal information.

## Hosting

GitHub Pages serves main/root. Relative assets support the project basepath. This repository contains public website files only.
