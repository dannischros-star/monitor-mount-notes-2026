What this website does

We do not run tracking analytics, advertising pixels, sign-up forms or user accounts. We do not set cookies or use browser local storage. The desk-fit checker processes entries in browser memory; it does not transmit or save the values. Reloading the page clears the tool’s results.

Hosting requests

The website is hosted on GitHub Pages. Like other hosting providers, GitHub receives the technical information needed to serve requests, which may include an IP address, request time, browser information and the requested URL. We do not operate GitHub’s infrastructure or control its retention practices. See GitHub’s General Privacy Statement.

Links to other services

Manufacturer documents and GitHub Issues are external services. Following a link sends a request to that service, which handles it under its own policies. The site loads its fonts, styles, illustrations and JavaScript locally from this same GitHub Pages site; it does not embed third-party widgets.

Public feedback

The feedback link opens a public GitHub repository. Posting an issue may expose your GitHub profile and the information you include. Avoid personal or confidential information. Do not use public issues to send passwords, email verification links or account records.

Changes and questions

If the website adds a collection feature or a commercial integration, this notice should be updated before that feature is used. For a general question about this notice, use the public feedback page without sharing private details.
